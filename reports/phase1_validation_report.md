## 2. Ingestion & Architecture-Aware Chunking

### 2.1 PDF Ingestion Engine
- Implemented in `ingestion/pdf_parser.py` using PyMuPDF (`fitz`).
- Ingestion operates page-by-page, preserving strict page boundaries (`page_number`).
- Headings are extracted through font size differential heuristics and hierarchical regex pattern matching (`r'^\d+(\.\d+)*\.?\s+\S'`).
- Tables are captured as structured markdown/key-value text, retaining signal mappings and port definitions.
- Automatic version detection scans metadata and headers (`Version 1.0` vs `Version 2.0`).

### 2.2 Architectural Chunking Heuristics
Unlike fixed character sliding-windows, `chunking/hld_chunker.py` categorizes and partitions text based on AUTOSAR engineering concepts:
- **`component`**: Identifies SWCs, runnables, and component definitions.
- **`interface`**: Captures Sender-Receiver and Client-Server communication specifications.
- **`port`**: Detects P-Ports (provide) and R-Ports (require).
- **`signal`**: Isolates physical signals, data element types, and engineering units.
- **`dependency`**: Tracks directional relationships and functional data dependencies.
- **`table`**: Preserves port-signal and component-dependency matrix blocks.

Each chunk is assigned an immutable ID with full provenance:
`{doc_id_short}_v{version}_p{page:02d}_c{counter:02d}`
